A prompt is the instruction you give an AI tool. Our prompts are written so you can copy them and fill in a few details.

## Steps

1. Open a prompt from the Prompt Library and read the summary to check it suits your need.
2. Press **Copy prompt**.
3. Open the AI tool you want to use. Text prompts work in chat assistants. Image prompts need an image generation tool.
4. Paste the prompt into the message box.
5. Replace anything in [SQUARE BRACKETS] with your own details, such as the topic, date or organisation name.
6. Send the message and review the result carefully.

## Tips

- If the result is not right, ask for changes in plain words, for example "make it simpler" or "use warmer colours".
- AI tools often misspell words inside images. Add important text yourself in a design app.
- Always check religious facts, dates and names with a trusted source before sharing.
