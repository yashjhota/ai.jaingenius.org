Write an invitation for a Jain community event.

Event details:

- Event name: [EVENT NAME, e.g. "Pratishtha Mahotsav" or "Annual Swadhyay Shibir"]
- Organised by: [TEMPLE / SANGH / TRUST NAME]
- Date and time: [DATE AND TIME]
- Venue: [FULL ADDRESS]
- Programme highlights: [LIST, e.g. puja, pravachan, cultural programme]
- Meal arrangements: [e.g. "Jain bhojan (no root vegetables) will be served" or "None"]
- Contact: [NAME AND PHONE NUMBER]
- RSVP by: [DATE, or "Not needed"]

Requirements:

- Language: [ENGLISH / HINDI / GUJARATI].
- Start with "Jai Jinendra".
- Keep it under 150 words, polite and easy to read on a phone.
- Use only the details given above. Do not add rituals, dates or names that are not listed.
- End with a short line of welcome from the organisers.

Then write a one-line version for a WhatsApp status.
